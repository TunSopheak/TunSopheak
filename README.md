## 🚀 Featured Project

### Smart Classroom with AI Monitoring

An **IoT + AI final demo project** that supports smarter classroom management through:

- FACE attendance
- QR backup attendance
- AI monitoring workspace
- Phone/book/person detection
- Attendance reports
- Mobile responsive dashboard
- LAN demo support

**Tech stack:** FastAPI, Jinja2, SQLite, OpenCV, YOLO, Raspberry Pi 5 concept.
